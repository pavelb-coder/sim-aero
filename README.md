# АэроЛаб — виртуальная лаборатория Аэроквантума

Браузерный стенд для **Аэроквантума** (Кванториум):

- сайт без внешних зависимостей (чистый HTML/CSS/JS, Canvas + SVG), работает офлайн;
- для школьников 9–17 лет и наставников, бесплатно.

## 🌐 Онлайн-версия (GitHub Pages)

**https://pavelb-coder.github.io/sim-aero/**

Открывается в любом браузере без установки — можно кидать ссылку ученикам.

## 💻 Запуск локально (порт 8085)

Подойдут **Node.js ≥ 18** (без npm-зависимостей, как в ХимЛаб 3D) или **Python 3** (уже есть на Ubuntu, на Windows ставится с python.org). Порт всегда **8085**.

**Windows** (двойной щелчок по файлу в папке проекта):

| Файл | Что делает |
|---|---|
| `start-windows.bat` | Универсальный запуск: подхватит Node.js, иначе Python 3; браузер откроется сам (рекомендуется) |
| `start-windows.ps1` | То же на PowerShell 5.1+ (ищет свободный порт, открывает браузер) |

Если порт 8085 занят, Node-сервер сам возьмёт следующий свободный (8086…8095); то же делает и `start-windows.ps1`. Порт меняется переменной `PORT` (`set PORT=8090 && start-windows.bat` или `$env:PORT=8090; .\start-windows.ps1`).

**Ничего сам не ставит без спроса:** если на компьютере нет ни Node.js, ни Python 3, скрипт сам предложит поставить **Node.js LTS через встроенный `winget`** (Windows 10/11) — ответьте «Y», и стенд поднимется сам. Иначе установите вручную: **Node.js LTS** — https://nodejs.org/ (`winget install OpenJS.NodeJS.LTS`) · **Python 3.9+** — https://www.python.org/downloads/ (отметьте «Add python.exe to PATH»).

**Если при вводе `python` открывается Microsoft Store** — это «заглушка» Windows, а не настоящий Python: либо закройте магазин и пользуйтесь `start-windows.bat` (он предложит поставить Node), либо поставьте Python с python.org, либо в «Параметры → Приложения → Дополнительные параметры приложений → Псевдонимы выполнения приложений» отключите пункты `python.exe` / `python3.exe`.

Полезно в мастерской: при первом запуске Windows может показать предупреждение брандмауэра — разрешите для частных сетей, если стенд будут открывать с других компьютеров класса (адрес покажет сам сервер, он слушает `0.0.0.0`).

Сценарий PowerShell, если политика исполнения не даёт запустить: `powershell -ExecutionPolicy Bypass -File .\start-windows.ps1` (или правый клик → «Выполнить с помощью PowerShell»).

**Ubuntu / Linux**:

```bash
./start-ubuntu.sh   # Node.js (если нет — встроенный Python 3)
# или вручную:
node server.js          # npm start
node server.js --open   # то же + открыть браузер (npm run start:open)
python3 -m http.server 8085 --bind 0.0.0.0
```

Затем откройте **http://localhost:8085**

### Node-сервер: переменные окружения

`node server.js [--open]` отдаёт статику из корня репозитория и ничего не требует, кроме Node.js: Brotli/gzip для текстовых файлов, `no-cache` для разметки и скриптов, сутки кэша для картинок/шрифтов, автоперебор порта при занятом 8085.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `8085` | порт (можно и аргументом: `node server.js 8090`) |
| `HOST` | `0.0.0.0` | адрес привязки |
| `FRAME_ANCESTORS` | `*` | кто может встраивать сайт во iframe (CSP `frame-ancestors`) |

Пример для школы с Moodle на своём домене:

```bash
FRAME_ANCESTORS="https://moodle.school.ru 'self'" node server.js
```

Сервер также отдаёт корректные MIME-типы и UTF-8, сжимает текстовые файлы gzip, закрывает path traversal и ставит `nosniff` / `Referrer-Policy`.

## Модули

0. **Конструктор БПЛА** — подбор рамы, винтомоторов, ESC, АКБ и полётного контроллера; расчёт взлётной массы, тяги, T/W, тока и времени висения; диагностика совместимости (рама/винты, напряжение, токи, отдача батареи); 3 задания с автопроверкой; схема коптера сверху с направлением вращения моторов.
1. **Аэродинамическая труба** — обтекание крыла (NACA 2412 / NACA 0012 / плоско-выпуклый / плоская пластина), угол атаки, скорость потока, C_y, C_x, качество K, число Re, центр давления; визуализация срыва потока и полярная кривая C_y(α); задания с автопроверкой.
2. **Трубка Вентури** — уравнение неразрывности и Бернулли: пьезометры, расчёт v₁, расхода Q, ΔP и Δh.
3. **Воздушный винт** — оценка тяги (импульсная теория, FM = 0,65): диаметр, шаг, обороты → тяга, мощность, скорость по шагу, взлётная масса квадрокоптера.
3A. **Симулятор полётного контроллера** — аналог стенда Betaflight: PID-бенч с живым графиком отклика на ступеньку (ступенька 0→25°, подбор P/I/D/FF, пресет «звенит — почини!»), вкладка «Моторы и микшер» (ARMED, газ/крен/тангаж/рысканье → M1–M4 по X-микшеру), учебная консоль CLI (help / status / dump / get / set / save).
4. **Квиз «Аэро-Эрудит»** — 12 вопросов с объяснениями и рангами.
5. **Формулы и методичка** — формулы Аэроквантума и 5 занятий для наставника.
3C. **Симулятор сборки квадрокоптера** — монтажный стол: реальный порядок билда (силовая цепь → BEC 5В → сигнальные провода → периферия), кликайте контакт в контакт; типы цепей проверяются (VBAT ≠ 5В-логика, UART кроссом TX↔RX, фазы ESC↔мотор по номерам); КЗ питание→земля = дым, встряска и счётчик сгоревших проводов; чек-лист из 20 точек сборки, ARM-кнопка открывается только при полной схеме.
3B. **Симулятор Pixhawk** — ArduPilot-стиль: мастер настройки (акселерометр с «пузырьковым» уровнем → гироскоп с 3-секундным удержанием → магнитометр с вращением на 720° → захват MIN/MAX радио → тест двигателей без пропеллеров), редактор ~36 параметров с поиском и скачиванием `params.param`, 2D-сценарии failsafe (потеря связи → RTL, просадка батареи → посадка).
6. **Наставнику** — журнал ученика (10 пунктов по программе), 10 достижений с сохранением в браузере, печатный «Допуск к полётам» (A5-альбомная, с QR-кодом и строкой подписи).

## Структура

```
index.html        — разметка и стили (один файл)
js/main.js        — вкладки, утилиты
js/tunnel.js      — аэродинамическая труба (физика + Canvas)
js/venturi.js     — трубка Вентури
js/prop.js        — расчёт воздушного винта
js/builder.js     — конструктор БПЛА (каталог, расчёт, диагностика)
js/fcsim.js       — симулятор полётного контроллера (PID-бенч, микшер, CLI)
js/pixhawk.js     — симулятор Pixhawk (мастер настройки, параметры, failsafe)
js/wiring.js      — симулятор сборки квадрокоптера (монтажный стол, чек-лист, ARM)
js/teacher.js     — раздел наставника (журнал, достижения, печать допуска)
start-windows.bat — запуск на Windows (Node.js → Python 3), браузер сам
start-ubuntu.sh   — запуск на Ubuntu/Linux (то же), браузер сам
start-windows.ps1 — то же на PowerShell 5.1+ (с поиском свободного порта)
server.js         — статический сервер на чистом Node.js (без зависимостей, v1.1.0)
package.json      — npm-скрипты start / start:open, engines node >= 18
```

Симуляция коэффициентов — учебная (упрощённая). Для точных расчётов используйте продувку.
