# mod_aerolab

«АэроЛаб: аэробенч» — активность Moodle 4.5: встроенный АэроЛаб во iframe,
автоматическая фиксация достижений (postMessage), оценка в журнал, отчёт учителя с CSV.

См. подробную инструкцию: **[../README.md](../README.md)**.

Быстрая установка:

```bash
cp -r moodle/mod/aerolab <moodle-root>/mod/
# затем Администрирование → Уведомления → очистить кэши
```
